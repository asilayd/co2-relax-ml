# co2-relax-ml

Суррогатные модели релаксационных членов для неравновесных течений CO₂.

Курсовая работа, кафедра гидроаэромеханики, матмех СПбГУ.

## Задача

В многотемпературном описании неравновесного течения CO₂ уравнения колебательной
релаксации содержат правые части — релаксационные члены `R`, скорости изменения
числа колебательных квантов в единице объёма (м⁻³·с⁻¹). Их прямой расчёт требует
свёртки поуровневых коэффициентов скорости по квазистационарному распределению,
то есть кратных сумм по колебательным уровням, и выполняется в каждой ячейке
расчётной сетки на каждом шаге по времени.

Цель работы — построить суррогатную модель

```
(T, T₁₂, T₃) → (R_VT2, R_VV23, R_VV123)
```

воспроизводящую результат прямого расчёта с соблюдением физических ограничений:
сохранения числа квантов, корректного знака и точного обращения в ноль на
термодинамическом равновесии.

## Физическая постановка

Молекула CO₂ имеет три колебательные моды. Моды ν₁ (1333 см⁻¹) и ν₂ (667 см⁻¹,
двукратно вырождена) объединены резонансом Ферми ν₁ ≈ 2ν₂ в комбинированную моду
с общим счётом квантов `i₁₂ = 2i₁ + i₂`; мода ν₃ (2349 см⁻¹) описывается отдельно.

Характеристические температуры: θ₁ = 1918 K, θ₂ = 960 K, θ₃ = 3380 K.

Состояние газа задаётся тремя температурами: `T` (поступательные и вращательные
степени свободы), `T₁₂` и `T₃` (заселённости соответствующих мод).

Рассматриваемые процессы:

| Канал | Переход | Баланс квантов |
|---|---|---|
| VT2 | CO₂(i₁₂) + M ⇄ CO₂(i₁₂−1) + M | мода 12: −1 |
| VV23 | CO₂(i₃, i₁₂) + M ⇄ CO₂(i₃−1, i₁₂+3) + M | мода 12: +3, мода 3: −1 |
| VV123 | CO₂(i₃, i₁, i₂) + M ⇄ CO₂(i₃−1, i₁+1, i₂+1) + M | то же |

## Данные

Исходный файл: `CO2_CO2_relaxation_results_large.csv`, 3 645 000 строк.

Входы: `n_CO2`, `T`, `T12`, `T3`, `partner`.
Выходы: `R_VT2_12`, `R_VT2_3`, `R_VV23_12`, `R_VV23_3`, `R_VV123_12`, `R_VV123_3`.

Сетка по температурам полная и регулярная: {1000, 1500, …, 5000} K, шаг 500 K.
Партнёр один (CO₂). Плотность пробегает ~5000 значений от 1·10²³ до 1·10²⁵ м⁻³.

Полные данные в репозиторий не включены — файл ожидается в `data/raw/`.
Для запуска без них в репозитории лежит подвыборка `data/sample.csv`.

## Результаты разведочного анализа

Проверены и подтверждены четыре точных соотношения:

| Соотношение | Невязка |
|---|---|
| `R_VT2_3 ≡ 0` | точно |
| `R_*_3 = −R_*_12/3` (VV23, VV123) | 1·10⁻¹⁴ |
| `R = 0` при `T = T₁₂ = T₃` | 0.0 |
| `R ∝ n²` | 2.7·10⁻¹⁴ |

Последнее позволяет вынести плотность аналитически: после деления на `n²`
величина от неё не зависит и приобретает смысл эффективного коэффициента
скорости (м³/с). Датасет сокращается до **729 физически различных точек**
при трёх входных переменных.

Положение нулевой поверхности каналов VV23 и VV123 описывается условием
обращения в ноль сродства процесса

```
φ = θ₃/T₃ − 3θ₂/T₁₂ − Δ/T,    Δ = θ₃ − 3θ₂ = 500 K
```

со спектроскопическими константами и **без подгоняемых параметров**:
среднеквадратичное отклонение 11 K при шаге сетки 500 K, медианная
относительная ошибка 0.34%. Контрольная подгонка `Δ` как свободного параметра
даёт 502.4 K. Тождество `Δ = θ₃ − 3θ₂` обеспечивает `φ ≡ 0` на равновесии,
то есть детальный баланс выполняется структурно.

Нулевые поверхности обоих VV-каналов совпадают (медианное расхождение 5 K),
что отвечает равенству энергетических дефектов `θ₃ − 3θ₂ = 500 K` и
`θ₃ − θ₁ − θ₂ = 502 K` вследствие резонанса Ферми.

Отсюда параметризация таргета:

```
R = A(T, T₁₂, T₃) · [1 − exp(−φ)]
```

Множитель в скобках вычисляется аналитически и обеспечивает точный знак,
положение нулевой поверхности и равенство нулю на равновесии. Обучению подлежит
только гладкий положительный множитель `A`.

## Структура репозитория

```
configs/                    конфигурации экспериментов
data/
  raw/                      исходные данные (не в гите)
  processed/                подготовленные датасеты (не в гите)
  sample.csv                подвыборка для запуска без полных данных
notebooks/
  01_eda.ipynb              разведочный анализ, проверка инвариантов
  02_affinity_target.ipynb  параметризация таргета
scripts/                    точки входа, запускаются из терминала
src/co2relax/
  physics.py                константы CO₂, сродство процессов
  data.py                   загрузка, проверка инвариантов, подготовка
  models.py                 архитектуры
  baselines.py              сплайн-интерполяция
  train.py
  evaluate.py
experiments/                результаты запусков (веса не в гите)
reports/figures/            графики
tests/                      проверки инвариантов
```

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
pip install -e .
nbstripout --install
```

PyTorch ставится отдельно, команда зависит от платформы:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu121   # CUDA
pip install torch                                                       # macOS (MPS)
```

## Запуск

```bash
python scripts/make_sample.py          # собрать data/sample.csv из полных данных
jupyter notebook notebooks/01_eda.ipynb
pytest tests/                          # проверка инвариантов
```
