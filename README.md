# co2-relax-ml

Суррогатные модели релаксационных членов для неравновесных течений CO₂.

Курсовая работа, кафедра гидроаэромеханики, матмех СПбГУ.

## Задача

В многотемпературном описании неравновесного течения CO₂ уравнения колебательной
релаксации содержат правые части — релаксационные члены `R`, скорости изменения
числа колебательных квантов в единице объёма (м⁻³·с⁻¹). Их прямой расчёт требует
свёртки поуровневых коэффициентов скорости по квазистационарному распределению,
то есть кратных сумм по колебательным уровням, и выполняется в каждой ячейке
расчётной сетки на каждом шаге по времени.

Цель — построить суррогатную модель

```
(T, T₁₂, T₃) → (R_VT2, R_VV23, R_VV123)
```

с точным выполнением физических ограничений: обращения `R` в ноль на
термодинамическом равновесии, корректного знака и сохранения числа квантов.

## Физическая постановка

Молекула CO₂ имеет три колебательные моды. Моды ν₁ (1333 см⁻¹) и ν₂ (667 см⁻¹,
двукратно вырождена) объединены резонансом Ферми ν₁ ≈ 2ν₂ в комбинированную моду
со счётом квантов `i₁₂ = 2i₁ + i₂`; мода ν₃ (2349 см⁻¹) описывается отдельно.
Характеристические температуры: θ₁ = 1918 K, θ₂ = 960 K, θ₃ = 3380 K.

| Канал | Переход | Δi₁₂ | Δi₃ | Дефект энергии |
|---|---|---|---|---|
| VT2 | CO₂(i₁₂) + M ⇄ CO₂(i₁₂−1) + M | −1 | 0 | — |
| VV23 | CO₂(i₃, i₁₂) + M ⇄ CO₂(i₃−1, i₁₂+3) + M | +3 | −1 | θ₃ − 3θ₂ = 500 K |
| VV123 | CO₂(i₃, i₁, i₂) + M ⇄ CO₂(i₃−1, i₁+1, i₂+1) + M | +3 | −1 | θ₃ − θ₁ − θ₂ = 502 K |

## Подход

Релаксационный член представляется в виде

```
R = A(T, T₁₂, T₃) · [1 − exp(−φ)]
```

где сродство процесса `φ` вычисляется по спектроскопическим константам:

```
φ_VT2   = θ₂/T₁₂ − θ₂/T
φ_VV23  = 3θ₂/T₁₂ + Δ/T − θ₃/T₃,        Δ = θ₃ − 3θ₂
φ_VV123 = (θ₁+θ₂)/T₁₂ + Δ′/T − θ₃/T₃,   Δ′ = θ₃ − θ₁ − θ₂
```

Множитель `[1 − exp(−φ)]` входит в модель **структурно**, а не извлекается из
данных делением:

```python
R_pred = exp(log_A(x)) * factor(φ)      # деления на малую величину нет
loss   = f(R_pred, R_true)              # потери вычисляются по R
```

Это даёт три гарантии, не зависящие от весов сети: `R = 0` при `φ = 0`,
положительность `A` (выход как `exp(log A)`) и, следовательно, корректный знак.

## Результаты

**Данные.** Плотность факторизуется точно (`R ∝ n²`, невязка 2.7·10⁻¹⁴), поэтому
исходные 3 645 000 строк сводятся к **729 физически различным точкам** без потери
информации. Три из шести выходных столбцов восстанавливаются из остальных.

**Проверка сродства.** Положение нулевой поверхности воспроизводится **без
подгоняемых параметров**: RMS 11 K при шаге сетки 500 K, медианная относительная
ошибка 0.34%. Контрольная подгонка `Δ` даёт 502.4 K против теоретических 500 K.

**Сравнение моделей** — худший случай по 4 схемам валидации × 3 каналам:

| Модель | Худшая медиана | Худший p95 | Невязка на равновесии | Ошибки знака | Мин `R²` |
|---|---|---|---|---|---|
| **Сеть с физикой** | **1.0·10⁻²** | **4.7·10⁻²** | **4.7·10⁻¹⁶** | **0** | 0.99959 |
| Сплайн по R | 1.3·10⁻² | 8.5·10⁻² | 2.0·10⁻² | 1.7·10⁻³ | 0.99976 |
| Сеть без физики | 4.8·10⁻² | 1.7·10⁻¹ | 7.9·10⁻² | **0** | 0.9947 |
| Сплайн по A | 1.1·10⁻¹ | 3.0 | **4.8·10⁻¹⁶** | 8.1·10⁻² | −0.545 |

Физически-информированная сеть лидирует по четырём критериям из пяти и не имеет
режимов отказа. У каждой альтернативы такой режим есть: сплайн по `R` нарушает
равновесие на 2·10⁻²; сплайн по `A` полностью теряет предсказательную способность
на экстраполяции; сеть без физической структуры уступает по всем критериям.

Невязка 2·10⁻² соответствует паразитному дрейфу равновесного состояния за время
порядка 10 мкс при газодинамических временах 1 мс.

**Устойчивость ограничений.** По всем 48 прогонам подбора гиперпараметров невязка
не превышает 4.8·10⁻¹⁶, ошибок знака нет ни одной. Точность зависит от
конфигурации в 7 раз, выполнение ограничений — не зависит вовсе.

**Дифференцируемость.** Якобиан `∂R/∂(T, T₁₂, T₃)` вычисляется автоматическим
дифференцированием по всей цепочке, включая множитель; сверка с численной
производной — 0.4%. Нужен для неявных схем, которых требует жёсткость системы.

Подробное описание методики, метрик и схем валидации — в `docs/methodology.md`.

## Запуск

Репозиторий самодостаточен: `data/core.csv` содержит все 729 точек, поэтому
ноутбуки запускаются без исходного файла.

```bash
jupyter notebook notebooks/03_neural_model.ipynb   # сравнение моделей, ~3 мин
python scripts/sweep.py --seeds 2                  # подбор гиперпараметров, ~3 мин
python scripts/make_core.py                        # пересборка core.csv из сырых данных
```

Обучение на 729 точках занимает секунды на CPU; GPU не требуется.

Минимальный пример:

```python
from co2relax.data import load_core
from co2relax.splits import SPLITS
from co2relax.train import Config, train_model, predict, jacobian

core = load_core()
tr, te = SPLITS["прореживание сетки"](core)

net, hist = train_model(tr, Config(model="physics", hidden=128, depth=4, epochs=6000))
R = predict(net, te)          # (N, 3): VT2, VV23, VV123
J = jacobian(net, te)         # (N, 3, 3): ∂R/∂(T, T12, T3)
```
